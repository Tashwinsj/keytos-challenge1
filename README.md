# Don'tDash

A place was set for you.

Don'tDash is a fictional supper club. There is no account, no payment, and no real phone call. You are already seated. The evening is the whole product.

## Open it

Open `index.html` in a browser.

Or, from this folder:

```bash
python3 -m http.server 8765
```

Then visit [http://localhost:8765](http://localhost:8765).

The room keeps its own memory for as long as the tab is open. Nothing is saved, sent, or charged.
